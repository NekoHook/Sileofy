## About

**Sileofy** is a package repository for [Sileo](https://github.com/Sileo/Sileo), designed to make discovering and installing tweaks convenient.

## Add the Repository

1. Open **Sileo** on your jailbroken iOS device.
2. Navigate to the **Sources** tab.
3. Add the repository URL:

   ```text
   https://YOUR-USERNAME.github.io/Sileofy/
   ```

   Replace `YOUR-USERNAME` with your GitHub username and make sure GitHub Pages or your package-hosting setup is configured.

## Features

- 📦 Package distribution for Sileo
- 🛠️ iOS tweaks and modifications
- 🌿 Simple, community-friendly repository
